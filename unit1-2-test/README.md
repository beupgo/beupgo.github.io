# 原野英语 · Unit 1–2 阶段综合练习

依据用户提供的《外研版（三起）六年级上册英语单词表（2026秋新版）》以及“学到 Unit 2”的学习进度制作。本版按六年级校内单元／阶段练习的用途设计，采用选择题与填空题混合的线上作答形式；没有使用某所北京学校的真卷，不标称北京统一试卷题型。

## 本卷

50 个小题：20 道单项选择题、30 道填空题，每题 2 分，共 100 分，建议 60 分钟。选择题点击选项，填空题直接在卷面空格输入答案。

## 试卷版面与 iPad

- 整卷连续排版：卷头、分值表、六个大题与统一交卷区。
- 听力材料按题组显示，阅读短文只显示一次。
- 顶部目录和答题卡可定位大题／题目，“检查未答”跳转到未完成的题目。
- iPad 横竖屏、分屏和手机自动适配；选项及主要触控按钮至少 44 像素高。填空字号 18 像素，支持触屏键盘及外接键盘 Tab／Enter。
- 此次仅调整排版，沿用混合题型版的记录标识，已有答案、成绩和错题继续可用。


| 模块 | 小题数 | 分值 | 重点 |
| --- | ---: | ---: | --- |
| 听力与听写 | 10 | 20 | 单词听写、短语听写、听后补全记录 |
| 单词与词形 | 10 | 20 | 语境选词、词形辨析、拼写 |
| 四种时态 | 12 | 24 | 一般现在、一般过去、现在进行、一般将来 |
| 固定搭配 | 10 | 20 | share with、agree with、spend on/doing、pay for、donate to 等 |
| 句型填空 | 4 | 8 | 否定句、特殊疑问句、花费类动词转换、将来时疑问句 |
| 短文综合填空 | 4 | 8 | 在短文中填写动词和介词 |

核心词汇覆盖 Unit 1–2 的 41 个词条，语境中使用小学基础词汇；后续单元不作为新词考查目标。词形变化和上述搭配是复习拓展，不据词表推断教材中的全部语法教学内容。所有题目为原创练习。

## 作答与复习

- 可做完整试卷，也可从首页单独练一个模块。
- 自动保存选择和填空，刷新后续答；输入框按 Enter 聚焦下一题，最后一题不会自动提交。
- 作答区去除首字母、中文释义、动词原形和语法解题提示，仅保留题干与必要操作要求。
- 所有参考答案和解析均在交卷后显示。
- 有标记检查、交卷前未答提醒；计时仅供参考，不强制提交。
- 交卷后显示分数、全部参考答案、中文解析和听力原文。
- 错误和未答题自动加入错题本，重练答对后成为已掌握。
- 支持单题／批量错题重练、最近 50 次成绩、文字报告导出、学习备份导入导出。
- 完整词库仍保留六单元的 118 条记录，默认只显示已学 Unit 1–2。

每小题全对得 2 分，不倒扣分。忽略大小写、额外空格和常见标点；允许已列明的缩写形式和等价答案。句型题限定结构并按答案集合评分，不是开放作文的语义评分。

学习记录保存在当前浏览器中，按站点地址隔离；换设备需要导出／导入备份。导入经过确认后替换当前记录。混合题型版使用独立存储标识，旧版数据不会被覆写或套用到新题上。上一版纯填空网页保存在相邻的 unit1-2-written-v1 目录，旧备份可在那里导入查看。

## 微软 TTS

`audio/` 内是本版重新生成的 MP3，使用 Microsoft Edge Read Aloud TTS 的英式神经语音 `en-GB-SoniaNeural`，生成语速 `-10%`，通过开源 `edge-tts` 客户端合成。共 9 段，包括试听和 8 段试题材料；本次题型调整沿用这些有效音频。可重复播放和调速。

音频已生成并随包提供，学生无需账号或密钥，运行时不调用浏览器通用语音合成。文本、音色、语速见 `audio/manifest.json`。修改听力文本后须重新合成相应 MP3，不能只改 JSON。

## 本机使用

双击 `index.html` 可作答。推荐使用固定网址以保持学习记录一致：

```sh
cd /你的目录/unit1-2-test
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。移动文件时保留 HTML、JS、CSS 与 `audio/` 的相对位置。

## GitHub Pages 部署

1. 新建 GitHub 仓库，如 `english-practice`。
2. 解压后，将本目录内全部文件和 `audio/` 上传至仓库根目录；确保 `index.html` 位于根目录。不要只上传 ZIP，也不要额外包一层文件夹。
3. 仓库 **Settings → Pages → Build and deployment** 中，Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，Folder 选择 **/ (root)**，保存。
5. 等待部署结束，打开页面显示的网址，通常为 `https://用户名.github.io/english-practice/`。

无构建过程、数据库或外部 CDN 依赖。相对资源路径兼容仓库子路径。GitHub Pages 可用性取决于账户和仓库设置。静态站点的答案存在源码中，适用于自学与练习。

## 后续维护

`questions.json` 保存题目、答案、解析、听力文本以及每题关联的词库词条；`vocabulary.json` 保存完整词库。改动后运行 `python3 sync-data.py` 生成浏览器直接加载的 `data.js`。不要只修改其中一个副本。

词库保存在项目文件里供后续引用；新会话不会保证自动读取。文件中的版本名称沿用用户提供的词表，不是对教材出版版本的独立认证。
