# Unit 3＋Unit 6 自然与旅行联合测试

六年级校内单元／阶段练习取向的原创试卷，适配 iPad 整卷在线作答。依据用户提供的外研版（三起）六上 2026 秋词表编写；不是官方真题。

- 50 题，100 分，建议 60 分钟：20 道选择题、30 道填空题。
- 听力、词汇、时态、固定搭配、句型转换、阅读六部分。
- 交卷后显示分数、答案与解析；错题本支持重练、学习记录导出与导入。
- Unit 3 和 Unit 6 共 38 个单元词条、36 个不重复词条；完整六单元词库共 118 条，保存在 vocabulary.json。
- 填空题按已列出的可接受答案匹配，忽略大小写、首尾和连续空格及常用标点；每题全对得 2 分，无部分分。
- 音频由微软 Edge Read Aloud TTS 生成，en-GB-SoniaNeural 英式语音，语速 -10%；MP3 随网站部署，无需在网页放置密钥。
- 成绩和错题仅保存在当前浏览器，跨设备请手动导出和导入；本专项与 Unit 1–2 记录独立。

## 部署
将整个 unit3-6-test 文件夹上传到 GitHub Pages 仓库，访问 /unit3-6-test/。无需安装依赖或后端。保留 audio 文件夹。

修改 questions.json 或 vocabulary.json 后运行 `python3 sync-data.py` 更新 data.js。听力文字变更时需重新生成对应 MP3。
