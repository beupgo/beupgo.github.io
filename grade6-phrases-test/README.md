# 六年级上册固定搭配专题练习

根据用户提供的《外研版（三起）六年级上册英语单词表（2026秋新版）》Unit 1–6 编写的 HTML 在线练习。

60 组搭配与表达，60 题，满分 120 分，建议 70 分钟。30 道选择题、30 道填空题；每题 2 分。六个单元各一段微软听力，共 6 道听力选择题，已计入总题数。按六个单元组织整张试卷，也可以按单元或按搭配练习。

搭配清单覆盖原词表明确列出的全部多词短语，并补充词汇常见搭配。原表短语标为“原词表”，其他标为“词汇拓展”；依据仅为用户提供的词表，不声称覆盖教材全文未提供的全部表达。完整六单元词库仍保存在 vocabulary.json；collocations.json 为搭配清单。

交卷前不显示答案解析；交卷后自动评分并收录错题，支持重练、导出与导入备份。填空按接受答案列表匹配，忽略大小写、空格和常用标点；无部分分。记录保存在本浏览器，与另外两套试卷独立。

微软音频由 Microsoft Edge Read Aloud TTS / en-GB-SoniaNeural（英式，-10%）预生成。MP3 随站部署，不需要网页端密钥。适配 iPad 横竖屏与分屏。

部署时将整个 grade6-phrases-test 文件夹上传到 GitHub Pages，访问 /grade6-phrases-test/。无需后端。修改 questions.json 后运行 python3 sync-data.py；修改听力文字须同步重新生成 MP3。

填空按参考表达的单词数分为空格，每空一词；例如 go abroad 为两个独立空格。支持逐空保存、Enter 跳到下一空，整题全对计分。旧版学习记录与备份仍可使用。
